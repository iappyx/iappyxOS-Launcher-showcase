One-time Google Cloud setup (~5 min, do this first)
  1. Open console.cloud.google.com. Create a new project (or pick an existing one). Free, no billing required.
  2. Search top bar for "APIs & Services" → "Enabled APIs & services". Click Enable APIs and Services and enable each of: Gmail API, Google Calendar API, Google Drive API, Google Tasks API, Google Sheets API. (5 separate clicks.)
  3. Side menu → OAuth consent screen. User type: External if personal account; Internal if a Workspace org. Fill app name + your email. Save. Add scopes? Skip — the plugin requests them at sign-in time. Add yourself as a test user under "Test users".
  4. Side menu → Credentials → Create Credentials → OAuth client ID. Application type: TVs and Limited Input devices (for the device-flow we use). Name: anything. Copy both the Client ID and Client secret shown.
  5. Paste them below. (The "secret" here is published-with-the-app shape — same trust level as Microsoft's public client model.)

That's all. After this, every Connect Google account click below opens a Google sign-in page — no copying codes from URLs, no curl.

GitHub

Surface PR review queue, notifications, issues, starred repos, and per-repo stats. Auth is a Personal Access Token — no OAuth dance.

How to create a Personal Access Token (~2 min)
  1. Open github.com/settings/tokens?type=beta (fine-grained) or github.com/settings/tokens (classic).
  2. Fine-grained (recommended): Generate new token. Resource owner: yourself. Repository access: "All repositories" if you want repo traffic across everything, or pick specific ones. Permissions:
    • Repository: Contents:Read, Issues:Read, Pull requests:Read, Metadata:Read (mandatory), Administration:Read (for traffic stats — optional)
    • Account: Email addresses:Read (optional), Followers:Read (optional)
  3. Classic alternative: select scopes repo, notifications, read:user. Simpler but coarser-grained.
  4. Set expiration to No expiration if you don't want to come back here in a year — security trade-off is up to you.
  5. Generate token, copy it (you only see it once), and paste below.

Starts with ghp_ for classic PATs, github_pat_ for fine-grained.

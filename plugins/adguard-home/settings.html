AdGuard Home

Connect to your self-hosted AdGuard Home DNS ad-blocker. Credentials are stored encrypted; widgets never see them directly.

Examples: http://192.168.1.10:3000, http://adguard.local:3000, https://adguard.example.com. Port 3000 is AdGuard's default admin UI port. No trailing slash needed.

Send only if your AdGuard install requires login. Encrypted at rest with the device Keystore.

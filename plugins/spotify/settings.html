Spotify

Surface now-playing, queue, recently played, and transport controls in widgets and wallpapers. Spotify uses OAuth, so the one-time setup is a few steps — after that it auto-refreshes itself.

How to get a Client ID + Refresh Token (one-time, ~3 min)
  1. Open developer.spotify.com/dashboard on a desktop browser and create an app. Any name, any description.
  2. Set the Redirect URI to http://127.0.0.1:8080/callback (or any URL you control — you'll capture the redirect manually).
  3. Copy your Client ID.
  4. Open this URL in a browser (replace YOUR_CLIENT_ID and the redirect_uri to match step 2):
    https://accounts.spotify.com/authorize?response_type=code&client_id=YOUR_CLIENT_ID&scope=user-read-playback-state%20user-modify-playback-state%20user-read-currently-playing%20user-read-recently-played&redirect_uri=http%3A%2F%2F127.0.0.1%3A8080%2Fcallback
  5. Approve the app. Your browser is redirected to http://127.0.0.1:8080/callback?code=AQ…long-code…. Copy the code value.
  6. From a terminal, exchange the code for a refresh token:
    curl -X POST https://accounts.spotify.com/api/token -d grant_type=authorization_code -d code=THE_CODE -d redirect_uri=http%3A%2F%2F127.0.0.1%3A8080%2Fcallback -d client_id=YOUR_CLIENT_ID
  7. The response includes a refresh_token. Paste it below.

From your app at developer.spotify.com.

From step 7. The plugin trades this for short-lived access tokens on demand — no client secret needed.

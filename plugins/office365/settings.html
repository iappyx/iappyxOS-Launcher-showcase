One-time Azure app setup (~3 min, do this first)
  1. Open portal.azure.com → App registrations → New registration. (Free, works with any Microsoft account — no Azure subscription needed.)
  2. Name: anything (e.g. "iappyxOS Launcher"). Supported account types: "Accounts in any organizational directory and personal Microsoft accounts". Leave the redirect URI blank — device-code flow doesn't use one.
  3. Once created, copy the Application (client) ID from the Overview page and paste it below.
  4. Go to Authentication → set "Allow public client flows" to Yes. Save. (No platforms to configure.)
  5. Go to API permissions → Add → Microsoft Graph → Delegated. Add: offline_access, User.Read, Mail.Read, Calendars.Read, Tasks.Read, Files.Read.All, Notes.Read.All. Personal-account-only — no admin consent needed.

That's all. After this, every Connect Microsoft account click below opens a Microsoft sign-in page — no code-copying, no curl, no client secret.

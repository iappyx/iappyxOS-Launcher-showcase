Unraid

Surface system stats, Docker containers, parity, VMs and shares from your self-hosted Unraid box. Requires Unraid 7.0 or newer (older builds don't ship the GraphQL API).

How to create an API key (~1 min)
  1. In the Unraid web UI: Settings → Management Access → API Keys.
  2. Click Add Key. Name it something like iappyxOS.
  3. If your build offers scope selection, choose read for status-only widgets, or read + write if you want to start/stop containers, VMs, or parity from a widget. read + write is the easiest if you're unsure.
  4. Save and copy the key. It's shown once.
  5. Or via SSH on the server: unraid-api apikey --create.

Examples: https://tower.local, https://192.168.1.10, http://tower. HTTPS is the Unraid default (self-signed cert — the launcher accepts it on LAN). Plain HTTP works too but the key travels cleartext over your LAN.
